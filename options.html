Drive Folder Size — one-time setup

This extension talks to the Google Drive API directly from your browser using your own Google Cloud credentials — nothing goes through a third-party server. Setup takes about 5 minutes and only needs to be done once.

1. Create a Google Cloud OAuth Client ID

  1. Go to Google Cloud Console → APIs & Services → Library, pick or create a project, and click Enable on the Google Drive API.
  2. Go to OAuth consent screen. Choose External, fill in the required app name/email fields, and on the "Scopes" step add https://www.googleapis.com/auth/drive.readonly. Leave publishing status as Testing — then on the "Test users" step, add your own Google account email. Staying in Testing mode means Google never reviews the app; it just works for the accounts you list.

  4. Click Create. Copy the Client ID shown (not the client secret — this extension doesn't use one).

2. How it stays fast

The first time it needs folder sizes, the extension fetches your entire Drive's file list once (paginated — this can take anywhere from a few seconds to around a minute depending on how many files you have) and computes every folder's size as plain in-memory math from that. After that one sync, opening any folder is instant, for 24 hours, until it re-syncs.

Use "Sync now" after big uploads/deletes/moves if numbers look stale — it re-syncs immediately instead of waiting for the 24h refresh. Access tokens expire roughly hourly; if badges start showing "?", the toolbar popup will offer a one-click "Reconnect".

Notes & limitations

Only the list view on "My Drive" and folder pages is supported (not Grid view, Recent, Starred, or Shared with me). Native Google Docs/Sheets/Slides/Forms don't report a byte size via the API, so folders containing them will show a slightly undercounted total — hover a badge to see if that applies. This extension only requests read-only Drive access.
