Drive Folder Size: setup

This extension talks to Google Drive using your own Google Cloud credentials, so nothing goes through a third-party server. Takes about 5 minutes, once.

1. Google Cloud credentials

  1. Enable the Drive API in a Google Cloud project (pick or create one).
  2. OAuth consent screen: choose External, add scopes drive.readonly and drive.appdata (the second is only for the Drive backup in step 3 below, but adding it now saves a trip back here later), add yourself as a test user, leave publishing status as Testing.

  4. Copy the Client ID and Client secret into the boxes below.

2. Sync

The first sync reads your whole Drive once (a few minutes if you have a lot of files, that's normal). Every sync after that only checks what changed, so it's near-instant.

"Sync now" checks immediately instead of waiting. "Clear cache" forces a full resync, only needed if numbers look structurally wrong, not just stale. You'll need to reconnect roughly weekly (Google's limit for apps in Testing mode); a one-click "Reconnect" shows up in the toolbar popup when that happens.

3. Restore without a full resync

Reinstalling, or moving to a new computer, normally means redoing the full sync. Skip that with a saved snapshot instead: either option below just needs a quick catch-up sync afterward, not a full one.

Save/load a plain JSON file yourself. Works anywhere, no extra setup.

Stores it in a hidden folder in your own Drive instead, handy on a new computer with nothing to carry over yourself. Works as soon as you're connected above, as long as you added the drive.appdata scope in step 1.

Limitations

Works on My Drive's list view only (not Grid view, Recent, Starred, or Shared with me). Google Docs/Sheets/Slides don't report a byte size, so totals including them are slightly undercounted. Hover a badge to check. Read-only access to your files; the Drive backup above additionally needs write access to its own hidden folder, never to your actual files.
