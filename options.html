Drive Folder Size — one-time setup

This extension talks to the Google Drive API directly from your browser using your own Google Cloud credentials — nothing goes through a third-party server. Setup takes about 5 minutes and only needs to be done once.

1. Create a Google Cloud OAuth Client ID

  1. Go to Google Cloud Console → APIs & Services → Library, pick or create a project, and click Enable on the Google Drive API.
  2. Go to OAuth consent screen. Choose External, fill in the required app name/email fields, and on the "Scopes" step add https://www.googleapis.com/auth/drive.readonly. Leave publishing status as Testing — then on the "Test users" step, add your own Google account email. Staying in Testing mode means Google never reviews the app; it just works for the accounts you list.

2. How it stays fast

The first sync fetches your entire Drive's file list, paginated at 1000 files/request — Drive's pagination is inherently sequential (each page needs the previous page's token), so this can take anywhere from a few seconds to several minutes depending on how many files you have. This only ever needs to happen once.

Every sync after that uses Drive's "changes" API (the same mechanism Google's own Drive desktop client uses) to ask "what's actually different since last time" instead of re-listing everything — for most people that's a handful of files, one request, near-instant. A full resync only happens again if Google invalidates the old checkpoint (rare) or you use "Clear cache" below.

Use "Sync now" after big uploads/deletes/moves if numbers look stale — it checks immediately instead of waiting for the periodic refresh. "Clear cache" forces the next sync to be a full resync (use it if numbers ever look structurally wrong, not just stale). Access tokens themselves still expire roughly hourly, but a refresh token renews them silently in the background — no reconnecting needed. While your Cloud project's OAuth consent screen is in "Testing" mode, Google expires that refresh token after about 7 days regardless; when that happens (or if you ever revoke access from your Google Account), badges will show "?" and the toolbar popup will offer a one-click "Reconnect".

3. Restore without redoing the full sync

The full sync only ever needs to happen once — but reinstalling this extension, or moving to a new computer, normally throws that away and starts over. These skip that: whichever one you use, the very next sync afterward automatically fetches only what's changed since, the same as a normal incremental sync — just a bigger catch-up if the snapshot is old.

Saves (or loads) the current index as a plain JSON file you carry yourself — USB drive, email to yourself, whatever. Works on any computer, no extra setup or permissions.

Stores the same snapshot in a hidden "app data" folder in your own Drive — invisible in the regular Drive UI and never counted toward any folder's size (though, like any file, it does use a small slice of your Drive storage quota). Handy on a new computer: connect, then restore, no file to carry over yourself. Not automatic — back up after a sync worth keeping, restore right after a fresh install/reconnect.

Needs a scope this extension didn't request before (drive.appdata), so it only works after two one-time steps: add that scope on your Cloud project's OAuth consent screen (Edit app → Scopes → Add or remove scopes), then click "Disconnect" and "Connect & test" above once so the new consent actually gets granted — an existing connection keeps whatever scope it was originally given.

Speeding up the (one-time) full sync

Google Drive API quotas are generous by default (12,000 requests/minute is typical) and usually aren't the bottleneck — check Drive API → Quotas in your Cloud project if you want to confirm, but for most people a slow first sync just means a lot of files. Backup tools especially — phone photo sync, game-save backup tools, full computer backups — tend to create huge numbers of small files (100,000+ isn't unusual), and at 1000 files per sequential request that's genuinely a few hundred round-trips with no way around the sequencing. The live status above will call out rate-limit hits specifically if that ever turns out to be a real factor for you. Either way, once it's done once, it's done — see "How it stays fast" above.

Notes & limitations

Only the list view on "My Drive" and folder pages is supported (not Grid view, Recent, Starred, or Shared with me). Native Google Docs/Sheets/Slides/Forms don't report a byte size via the API, so folders containing them will show a slightly undercounted total — hover a badge to see if that applies. This extension only requests read-only access to your Drive files, plus (if you've set up the Drive backup above) read/write access to its own hidden app data folder — it never has write access to your actual files or folders.
